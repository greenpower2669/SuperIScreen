# SuperIScreen 🎬

Application Android expérimentale pour utiliser une vidéo locale comme fond d’écran animé.

**Important :** sur les Samsung Galaxy compatibles, le fond vidéo de l’écran de verrouillage peut déjà être appliqué depuis **Galerie → Vidéo → Définir comme fond d’écran → Écran de verrouillage**, sans installer d’application.

Le développement est effectué sur une branche dédiée ; `main` ne contient initialement que cette présentation.

Aucun média personnel ni vidéo sous droits tiers n’est publié dans le dépôt.
